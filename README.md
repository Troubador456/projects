# ALL my projects!

## PDF Scanner
- Description: Scans a paper from a picture and turns it into a pdf
- Instructions
  - Run all cells in the ipynb and make sure to input your picture for the scanner to read
  - Then you can save the pdf to your files
  - And that's it!
- How it works (simplified)
  - Finds the corners
  - Eventually that helps it to find the edges of the page
  - Warps it to be completely straight (removes the distortion)
  - Converts it to grayscale and returns photo without error

## Messi vs Ronaldo Classifier

## Chatbot
